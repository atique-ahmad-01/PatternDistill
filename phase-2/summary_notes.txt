HYPOTHESES FOR REGRESSION (Int. Algebra & Number Theory)
---------------------------------------------------------
1. Distilled patterns too abstract/noisy — not concretely useful at inference
2. Both were already high vanilla performers — injected context confuses the
   model on problems it would have gotten right unaided
3. Number Theory requires multi-step symbolic reasoning that retrieved hints
   disrupt rather than guide


RECOMMENDATIONS FOR PHASE 3
-----------------------------
1. Re-distill or filter Int. Algebra and Number Theory pattern clusters
2. Subject-gated injection: only inject where subject type predicts a gain
3. Revisit similarity threshold (0.4) — may pull in too-distant patterns
4. Focus on better L5 patterns — largest group, most impact on overall delta

CONCLUSION
----------
Subject filtering is NOT the right fix:
- IA remained at 45.5% — subject filter had zero effect, confirming
  the problem is pattern quality within IA, not cross-subject retrieval
- Precalculus got worse (-15.4pp) — restricting to same subject reduced
  the candidate pool and forced worse matches
- The original Phase 2 root cause analysis was wrong: cross-subject
  retrieval in Phase 2 was coincidental, not causal

REVISED ROOT CAUSE
------------------
Intermediate Algebra patterns are fundamentally poor quality:
- 25% has_pattern=False (highest rate of any subject)
- Patterns are abstract/procedural mismatch — too problem-specific to
  generalise across IA questions
- High sim score (0.6-0.8) does not guarantee useful pattern match

NEXT STEPS (revised)
---------------------
1. Re-distill IA patterns with a better prompt — force more generalizable,
   step-level strategies rather than problem-specific hints
2. Consider injection threshold per subject — raise threshold for IA/NT
   to only inject when sim > 0.80 (very high confidence match)
3. Do NOT use subject filtering — it hurts more than it helps

→ All three implemented in Phase 2C (see below)

WHAT WORKED
-----------
- Subject-aware thresholds completely eliminated IA/NT regressions
  (both now at 0.0pp delta — no longer hurting)
- Step-level patterns + worked examples helped L1/L2/L3 significantly
- Prealgebra improved from +6.7pp to +13.4pp

REMAINING ISSUES
----------------
- Precalculus still hurting (-7.7pp) — injection confusing model on this subject
- L5 still not improving (50.0% both) — hardest problems resist injection
- IA/NT at 0.0pp delta — thresholds prevented regressions but injection
  still not actively helping (most IA/NT skipped due to sim < 0.75)
- Geometry dropped (noisy, n=5)

CONCLUSION
----------
Phase 2C is the best result so far (+2.0pp). The combination of step-level
patterns, worked examples, and subject-aware thresholds works. Ready to
proceed to Phase 3 fine-tuning with this injection mechanism as the baseline.


Root Cause Analysis                                                                                                                                                               
                                              
  Intermediate Algebra — 5 hurt, only 1 helped                                                                                                                                      
                                                                                                                                                                                    
  The injected patterns are mostly wrong-subject matches. Examples:                                                                                                                 
  - id=456 L1 got a simplifying exponents pattern (Algebra, not IA) — sim=0.646                                                                                                     
  - id=432 L5 got a continued fractions pattern when the problem needed something else — sim=0.588                                                                                  
  - id=428 L4 got a Cauchy-Schwarz pattern at sim=0.795 — high similarity but still led the model wrong                                                                             
                                                                                                                                                                                    
  The patterns themselves aren't bad — they're just retrieved for the wrong problem. The embedding similarity is picking up surface-level math notation overlap, not conceptual     
  match.                                                                                                                                                                          
                                                                                                                                                                                    
  Number Theory — only 2 hurt cases, small impact relative to the -12.5pp hit — the issue there is mainly small n (16) amplifying noise.                                            
                                                                                                                                                                                    
  Geometry — clean wins                                                                                                                                                             
  Patterns are concrete and procedural ("use Heron's formula, then Pythagorean theorem") — the model can directly apply them. IA patterns tend to be more abstract ("reindex by     
  letting n = j+k") which doesn't transfer well across problems.
