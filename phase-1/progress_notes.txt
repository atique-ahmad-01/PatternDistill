WHAT THE PATTERNS ARE USED FOR:

Method A — Memory Injection (method_a/)
  At inference time, embed the test problem, retrieve the most similar pattern
  from the bank, and inject it into the 1.7B prompt. The small model sees the
  pattern but has NOT been trained on it. Tests whether showing a pattern at
  runtime is enough.

Method B — Neural Distillation (method_b/)
  Fine-tune the 1.7B on the 400 pattern-augmented examples using LoRA. At
  inference time, no pattern is injected — the model must rely on what was
  baked into its weights during training. Tests whether internalizing patterns
  beats just seeing them.

RESEARCH QUESTION:
  Which works better — injecting patterns at runtime (A) or distilling them
  into weights (B)?

**Purpose of the Generated Patterns**

**Method A — Memory Injection (`method_a/`)**

* During inference, the test problem is embedded and matched with the most similar pattern from the pattern bank.
* The retrieved pattern is injected into the **1.7B** model's prompt.
* The model is **not fine-tuned** on these patterns; it only uses them at runtime.
* This evaluates whether providing reasoning patterns during inference improves performance.

**Method B — Neural Distillation (`method_b/`)**

* Fine-tune the **1.7B** model using **LoRA** on the **400 pattern-augmented examples**.
* During inference, **no pattern is injected**.
* The model relies solely on the reasoning patterns learned during fine-tuning.
* This evaluates whether internalizing reasoning patterns into the model weights performs better than runtime pattern injection.
